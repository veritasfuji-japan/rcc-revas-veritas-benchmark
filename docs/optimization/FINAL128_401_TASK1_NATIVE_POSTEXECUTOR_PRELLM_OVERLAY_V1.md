## Why post-tool / pre-LLM matters

This is an actually observed **in-process Native pipeline execution boundary**,
rather than merely a synthetic role ordering in a JSON request.
The replay confirms Native can carry a B-only source-owned developer treatment
at this seam without changing A's context, trimming the full tool catalogue,
or removing the lower-trust injected data.

The execution is a **bounded offline replay** with a locally scripted
read-only first assistant tool call and locally scripted terminal text. The
offline first and terminal responses are NOT generated by an independent
Provider. A/B first prompts are the same, but no actual model decisions,
repeated inference, real effectful tool proposals or Native scoring occur.

## Fail-closed guards

- Any wrong exact source prompt, wrong Native object, mutated native initial
  bank snapshot, changed DirectAttack payload/slot, changed full native
  runtime/tool list, or incorrect Native pipeline shape is rejected.
- A real Native YAML tool result with a different structure/content or missing
  attacker subject is rejected before B overlay.
- The native assistant FunctionCall/ToolResult IDs must match within an arm;
  distinct A/B offline IDs cannot be substituted for real Provider IDs.
- Overlay contains no malicious subject text, scorer GOLD or authorization.
  The alias profile is source-owned and pinned to the unchanged Native YAML.
- Effectful tool dispatch is NOT claimed to be protected here. Only the
  fixed read-only tool call is executed by Native ToolsExecutor. #399 proves
  a separate bounded, synthetic write refusal, not full coverage.
- No network client, Provider sender, scorer or real-world bank effect is run.
  Redacted evidence contains hashes/status/zero-count and no raw payload,
  private data, tool conversations or account data.

## Important limitations

A registered source-owned hook is not proof that the **production** Native
Runner is patched/deployed with this hook, nor that the B developer-role
treatment is benchmark-official. This is an in-process tested integration
proposal; authentic real-model A/B responses and full source-owned Native
history are still required. Raw `SourceOwnedPostExecutorHook` is installed
on this single local pipeline instance, not the frozen AgentDojo package,
and does not install a global bypass-resistant executor/IAM/egress wall.

Do not promote offline pass to independent A/B Utility, attack-success
measurement, canonical Native score, signed authority or production PROVEN.
