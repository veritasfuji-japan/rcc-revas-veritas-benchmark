# Closed bounded Native + Unix TLS + signed model under IP denial

This disposable root CI profile joins the previously separate bounded Native
history, retained role authority, actual VERITAS Bind, first raw TLS archive,
signed ledger gate, retained GitHub API **model**, and eight actor UID IP deny
proofs in one live isolated network namespace. It does not deploy a VM profile.

The Native runtime is UID 61108; UID 61101 is the untrusted agent probe. Each
actual SDK request is authorized online against the prior signed archive and
runtime tool observation, with separate issuer (61105), Custody (61106), runtime
(61108), backend (61103), archive recipient (61107), and ledger (61109) roles.
The continuation hashes change with the observed history; they are not the
previous fixed eight request hashes.

The new module explicitly injects only three fixture transport dependencies:
`task4_native_local_https_v1.call`, `.server_class`, and
`task4_native_raw_ingress_v1.dispatch`. It leaves signature checks, policy,
consumption, original SDK execution, real Bind, signed gate, and model validators
unchanged. Backend HTTP travels over TLS over AF_UNIX. The client pins the
backend kernel UID before TLS, requires the local CA, hostname and enrolled leaf,
and never resolves DNS or falls back to IP. The server refuses seven other actor
UIDs before TLS/HTTP parsing. The synthetic bearer credential is local test
material. TLS here authenticates the server; the backend client is authenticated
by SO_PEERCRED and the synthetic credential, **not a backend client certificate**.
The ledger independently retains its existing real mutual TLS over AF_UNIX with
kernel UID/certificate/command checks.

`api.openai.com` in the existing signed context and local fixture certificate is
an API-shaped synthetic label. No public name resolution, public Provider HTTPS
client, API credential or external request is used by this transport.

## Trial and retained evidence

The runner refuses existing role UIDs 61101–61109, existing retained deployment
anchors, and existing output paths. It exports root-owned tracked source and the
three pinned external code trees, then starts a fresh `unshare --net` child. Only
loopback is raised. The parent network namespace is never selected for rules.

The report records baseline IPv4/IPv6 TCP/UDP success for all eight actors,
installs the exact existing eight-UID fixture reject policy, checks 32 per-flow
counter-joined denials, and checks four UID 0 controls. All bounded Native
operations and restarts run before policy removal. It then checks another 32
counter-joined denials, records the unchanged policy/handles except counters,
removes the disposable namespace table, and checks all 32 baseline flows again.
UID 61109 is the excluded local ledger control, not an IP-restricted actor.
The fixed fixture table name is reused exclusively in this new disposable
namespace; no host trial or host rollback tool is called.

The existing bounded exercise and validators join:

- Eight actual changing-history SDK completions and two actual scripted Native
  terminals/scorers, with 50 invalid issuer RPCs refused.
- Single-use durable consumption before actual Bind, whose denied path applies
  zero effects and allowed path applies exactly one backend effect.
- Eight raw HTTP responses captured over Unix TLS and encrypted/fsynced before
  HTTP parsing; a fresh archive-owner process recovers the exact raw bytes.
- Sixteen signed model mutations, original nonces/signatures, exact model
  readback before signing, and real ledger mTLS certificate/UID/command joins.
- Actual ledger and issuer SIGKILL/reopen with the same revision 16 snapshot;
  Custody restart and 16 replay refusals without new posts or raw events.
- 56 authenticated status requests and eight raw POST TLS handshakes, the seven

The wrapper replays the original cryptographic validators against the complete
nested reports and checks their canonical digests. Its JUnit has 18 checks,
separate from 16 portable admission/transport tests. Both are mandatory and must
have zero skips in the root Native workflow. Timeout kills the complete fixture
process group; normal teardown stops child services and retires only the exact
owned disposable retained anchors. Partial/corrupt anchors are not repaired.

## Limits

The GitHub backend is a retained SQLite implementation of the reviewed API
model, not a remote GitHub experiment or independent witness. One root CI
administrator controls all enrollment and test keys. Custody is trusted; this
proof does not establish resistance to a compromised Custody with its synthetic
backend credential. The new raw transport adapter is explicitly selected and
is not evidence for a default public Provider transport. The fixture archive
origin strings retain the original local TLS schema; AF_UNIX provenance is
recorded explicitly in peer observations.

This is not the bounded 15-second operator host lease, a VM cutover, an operator
service UID 109 integration, a live research admission or an operator clock/key
attestation. Parent table-name comparison is a negative control, not a full host
policy attestation. The currently expired operator readiness window is not
renewed. Operator tokens, retained signer secrets and preparation files are not
loaded or changed. No fault-response-loss scenario is newly claimed by this
normal integration proof.

**REAL_PROVIDER_NO_GO / UTILITY_UNSCORED /
PRODUCTION_BYPASS_RESISTANCE_NOT_PROVEN** remain in force.
