# Task15 composed admission boundary V1

After #244, a registered local address/rent/refund scope must remain evidence rather than dispatch authority. The new read-only boundary verifies the original live session/capture before and after deriving a frozen review. It binds the immutable full RCC candidate, actual generation ordinal, current acquired pre-state, original request, receipt anchor, native implementation/parser/schema identities and parent local observation. It does not construct a runner, execution-authority issuer, receipt store, RCC gate, Bind dispatcher, provider or scorer.

A wrapper profile slot 0/1/2 and an actual generation ordinal 3/9/14 are separate fields. Both pairing hashes are shown for review, but the actual full RCC identity is checked against the registered captured binding. An isolated component runner's proof-slot identity is not automatically converted into an actual-generation or composed dispatch identity. Wire provenance and actual generation/runtime integration remain separate obligations.

| Operation | Frozen semantics retained | Separate admission obligations |
|---|---|---|
| Address | Existing supported/request/shape/street predicates retained; original city_bound remains recorded false for the pinned request | Only the already-proved street/city representation may compose city; live native profile and all other predicates remain required |
| Rent | Every existing supported/request/shape/record/recipient/amount predicate is retained | Registered existing-record profile, exact candidate, preserved operational metadata and other records |
| Refund | Legacy supported_profile=false and date_authority_present=false retained verbatim; original request/amount predicates stay true | Distinct current signed root/profile/policy, owned shared receipt reservation, atomic consume before dispatch, clock/revocation/state checks and separate controlled eligibility |

Each review lists 8 common obligations plus 2/2/5 step obligations, all REQUIRED_UNPROVEN. It never replaces them with supplied bools, COMMIT labels, exported witness objects or earlier effects. In particular actual RCC review, actual Bind adjudication, final sink acceptance, consumed slot and one-use capability remain false. New local evidence cannot manufacture these proofs. The existing benchmark authority signal is not accepted as an input to this boundary. Original isolated runners and validators remain unchanged.

A review payload is detached and immutable; its full digest includes the original issued context digest. Verification must recompute the same review against the current original live registry. Cross-session copies, changed candidate/state/ordinal/receipt/parent/native identities, obligation-success labels or permission flags fail closed. Retired/closed scopes cannot pass. Callback returns after closure fail through #244's active-phase checks. Failure preserves earlier local observations. Successful repeated reviews consume nothing: this is a read-only review, not a single-use dispatch token or permit.

The prospective proof has 110 tests and recursively reproduces all 2099 frozen prior tests. Two A/B local lineages export six reviews, independently recomputed with fresh scope registries/keys and six detached native semantic transitions. Eighty-seven exported refusals are independently replayed: 45 review-field/self-attestation changes, 24 candidate substitutions and 18 lifecycle/state/clock/registry failures. Further native source/schema/dependency, equivalent foreign-session review, callback closure and non-session authority-signal tests fail closed. Native semantic probes are outside the new boundary module and never claim composed governed execution.

The trusted reader, original requester/account/friend mapping, metadata reviewer, fixture clock and Python process are owned harness assumptions. File/schema pin checks do not sandbox arbitrary trusted code or authenticate an external state/effect. Removing the original context digest produces portable content for a fresh-registry audit only; the exported original MAC is not independently authenticated. Portable content is not a capability. No restart persistence, durable global single use, external effect reconciliation or full Task15/Final128 execution is proven.

Provider/client/database/scorer calls, scorer/gold-derived authority, candidate repair and V13 reuse in this new boundary proof remain zero. Utility and injection success are not remeasured. Independent external validation, held-out generalization and production readiness remain unproven.
